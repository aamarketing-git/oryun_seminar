# 오륜미네랄 세미나 AI비서 (텔레그램)

세미나 일정·장소를 주면 **포스터를 만들어 텔레그램으로 이미지 그대로 전송**하고,
매주 **세미나 주간 리포트**를 자동으로 보내주는 비서입니다. 모두 **무료**로 운영됩니다.

구성은 3가지이며, 원하는 것만 켜도 됩니다.

| 기능 | 어디서 | 서버 필요? | 비용 |
|---|---|---|---|
| ① 앱에서 버튼으로 포스터 전송 | 상황실 웹앱 | ❌ 불필요 | 무료 |
| ② 텔레그램에 메시지 보내 포스터 받기 | 봇 (bot.py) | ⭕ 상시 실행 | 무료~ |
| ③ 주간 리포트 자동 전송 | GitHub Actions | ❌(깃허브가 실행) | 무료 |

---

## 0. 먼저: 텔레그램 봇 만들기 (5분, 공통)

1. 텔레그램에서 **@BotFather** 를 검색해 대화 시작 → `/newbot` 입력
2. 봇 이름과 아이디(끝이 `bot`)를 정하면 **봇 토큰**을 줍니다. (예: `7812345678:AAH...xyz`)
   - 이 토큰이 비밀번호입니다. 외부에 노출 금지.
3. **채팅 ID 확인**
   - 개인에게 받을 경우: 방금 만든 내 봇과 대화 시작(`/start`) → 아래 ②봇을 켜고 아무 메시지나 보내면 봇이 채팅ID를 알려줍니다.
   - 단톡방으로 받을 경우: 단톡방에 봇을 초대 → 방에서 아무 메시지나 보낸 뒤
     `https://api.telegram.org/bot<봇토큰>/getUpdates` 를 브라우저로 열면 `"chat":{"id":-100...}` 가 보입니다. 그 숫자가 채팅ID입니다. (단톡방은 보통 `-100`으로 시작)

## ① 앱에서 버튼으로 전송 (가장 간단, 지금 바로)

서버가 전혀 필요 없습니다. 상황실 웹앱만 있으면 됩니다.

1. 상황실 앱 → 관리자 로그인 → **설정(⚙️)** → **텔레그램 전송** 칸에
   - **봇 토큰**, **채팅 ID** 입력 후 저장
2. **포스터** 화면에서 세미나를 고르고 내용을 확인 → **[✈️ 텔레그램 전송]** 버튼 클릭
3. 지금 화면의 포스터가 **이미지 그대로** 텔레그램으로 전송됩니다.

> 스타일 A/B, 지도·사진, 인원 말풍선까지 화면에 보이는 그대로 전송됩니다.

---

## ② 텔레그램 대화형 봇 (메시지로 포스터 받기)

텔레그램에서 봇에게 세미나 정보를 보내면 포스터를 만들어 답장합니다.
봇은 **항상 켜져 있어야** 메시지를 받으므로, 아래 중 한 곳에서 실행하세요.

### 실행 방법 (공통)
```bash
cd telegram-bot
pip install -r requirements.txt
export TG_TOKEN="7812345678:AAH...xyz"   # 윈도우: set TG_TOKEN=...
python bot.py
```
켜진 상태에서 텔레그램 봇에게 아래처럼 보냅니다:
```
2026-11-15 / 14:00 / 국제건업건물 2층 / 인천시 부평구 동암남로 17,2층 / 50 / a
```
→ 순서: **날짜 / 시간 / 장소 / 상세주소 / 인원 / 스타일(a 또는 b)**
→ 포스터 이미지를 바로 보내줍니다. (`/help` 로 사용법 확인)

### 어디서 24시간 켜둘까? (무료~저가)
- **내 PC**: 필요할 때만 `python bot.py` 실행 (가장 간단, 무료)
- **Railway / Render 무료 플랜**: 깃허브에 올리고 연결하면 상시 실행 (무료 크레딧 범위)
- 비용이 걱정되면 ①(앱 버튼)만 써도 포스터 전송은 충분합니다.

## ③ 주간 리포트 자동 전송 (GitHub Actions, 무료)

매주 월요일 아침, **이번 주 세미나 일정 + 다음 주 예정·준비사항**을 텔레그램으로 보냅니다.

1. 이 `telegram-bot` 폴더를 **상황실 깃허브 저장소**에 함께 올립니다.
   (`.github/workflows/weekly-report.yml` 포함)
2. 깃허브 저장소 → **Settings → Secrets and variables → Actions → New repository secret** 에서 4개 등록:
   - `TG_TOKEN` : 봇 토큰
   - `TG_CHAT` : 리포트 받을 채팅 ID
   - `SUPA_URL` : `https://remgykeiwxpjhcocezin.supabase.co`
   - `SUPA_KEY` : 앱에서 쓰는 publishable key (`sb_publishable_...`)
3. 저장소 → **Actions** 탭 → '주간 세미나 리포트' → **Run workflow** 로 즉시 테스트.
4. 이후 매주 월요일 08:00(KST)에 자동 전송됩니다.
   - 시간을 바꾸려면 `weekly-report.yml` 의 `cron` 값을 수정하세요. (UTC 기준)

> ⚠️ 리포트는 Supabase 데이터를 읽습니다. Supabase가 **일시정지(Pause)** 상태면 읽지 못하니, 리포트를 쓰려면 Supabase를 **Resume** 해두세요.

## 폴더 구성
```
telegram-bot/
├─ bot.py              # ② 대화형 봇
├─ weekly_report.py    # ③ 주간 리포트
├─ poster.py           # 포스터 생성기 (스타일 A/B, 앱과 동일)

├─ assets/             # 배경 2종 + 폰트
└─ .github/workflows/weekly-report.yml
```

## 참고 — 카카오톡은?
카카오톡은 봇이 남에게/단톡방에 이미지를 자동 전송하는 것이 정책상 막혀 있고(비즈니스 채널 심사·발송비 발생),
개인 '나에게 보내기'만 제한적으로 가능합니다. 그래서 이미지 자동 전송은 **텔레그램**을 권장합니다.
추후 카카오 '나에게 보내기'가 꼭 필요하면 별도로 추가할 수 있습니다.
